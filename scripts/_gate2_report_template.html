GATE 2 — Instrument Tax

The SAME mutants, measured twice per episode: once through ground-truth state (L0, exactly what GATE 1 uses) and once through the real video → segmentation → re-identification → 3D reconstruction pipeline (L1). The gap between L0 and L1 on identical episodes is the instrument's own error floor.

What this answers that GATE 1 can't. GATE 1's survival curves compare ground truth against ground truth — they prove the detector math is correct, but say nothing about how much error a REAL measurement channel (a camera, tracking, reconstruction — the same channel a real model's video would go through) adds on top. GATE 2 answers that, by running the identical known defects through both channels and measuring the disagreement directly. Regenerate via python3 scripts/run_gate2.py (needs the remote GPU/Modal environment) then python3 scripts/render_gate2_report.py.

Key — what these terms mean

L0Ground-truth event

When (and via which risk, R2/R5) the detector fires when it can read the true simulator state directly — no camera, no tracking. Identical to what GATE 1's survival curves are built from.

L1Video-measured event

When the SAME detector fires when it only has real, rendered video to work with — segmented, tracked, and reconstructed back into a 3D trajectory by Phi first. This is what a real generated-video model will also go through.

ΔtEvent-time bias

L1's detected time minus L0's, averaged over episodes where BOTH fired. Positive means the video channel notices the defect later than ground truth does — the direct cost, in seconds, of measuring through video instead of state.

·Mean mask IoU

How well the tracked segmentation mask overlaps the true object silhouette, averaged over every visible frame (1.0 = perfect overlap). The core segmentation-quality floor.

·Occlusion-flag accuracy

How often the system's belief about whether the object is currently behind a known occluder matches the true visibility state.

·Position error

Mean distance (metres) between Phi's reconstructed 3D position and the true 3D position, over every frame the object was actually tracked.
