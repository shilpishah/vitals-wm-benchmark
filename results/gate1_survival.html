GATE 1 — Survival Curves

Kaplan-Meier survival over a population of mixed-mutant rollouts per scenario, state-space (ground truth), no video. Auto-generated from every results/l0_demo_*.json found on disk.

Not a "scorecard." This project's own design explicitly avoids a single aggregate score (AGENT.md §3.11) — a survival curve + termination profile is the report that stands in for one.

Every series is prefixed (T) / (C) / (B) and colored by that same category — (T) red = Truth, GATE 1's own state-space validation: the reference rollouts ARE the ground-truth physics, deliberately corrupted with a known planted failure time by the mutant library, run so the detector's recovered failure times can be checked against that known answer. (C) blue = Cosmos, a real video-generation model, scored through the actual Phi (SAM2/DINOv2 + 3D reconstruction) pipeline with no ground truth involved on the candidate side at all. (B) green = baseline models (e.g. constant-velocity extrapolation) scored through the identical pipeline as Cosmos, for a fair, apples-to-apples comparison. Multiple curves within one category get different SHADES of that category's color, not different hues. Treat small-sample (C)/(B) populations as illustrative, not statistically powered, until their n matches the (T) populations' own scale (see AGENT.md M6).

Regenerate the (T) curves via python3 scripts/run_l0_demo.py (per scenario), a (C) population via python3 scripts/run_cosmos_population.py, a (B) population via python3 scripts/run_eval.py --adapter <name>, then python3 scripts/render_survival_report.py.

Key — what these terms mean

R2Existence

sigma_existence — did the tracked object stop existing (vanished) or spuriously duplicate, compared to how much the reference ensemble's own existence varies at that instant? Fires on mutants like vanish / duplicate.

R5Kinematic

sigma_kinematic — did the object's motion (position/velocity) stop being physically plausible, compared to the reference ensemble's own spread at that instant? Fires on mutants like velocity_freeze / wrong_gravity.

·Censored

The rollout reached the end of the clip without R2 or R5 ever crossing its threshold — it didn't "fail" by this benchmark's definition, so its true failure time is only known to be ≥ the clip length, not exact. Same usage as a still-alive patient at a clinical trial's end.

αFalse-termination rate (GATE 1a)

Of a held-out population of uncorrupted reference rollouts (no planted defect at all), the fraction the detector still fired on anyway. This is the detector's own false-positive floor — it should sit near the target α (≈0.01), and PASS is defined generously (≤5×α) since this is a finite-sample estimate.

VI₅₀Validity interval

The median time at which a rollout in the population has failed (Kaplan-Meier's own quantile). Reported with a bootstrap 95% CI, not as a bare point estimate.

·Termination profile

Of the rollouts that DID fail, what fraction failed via R2 vs R5 — i.e., which failure mode dominates this population, not just when failure happened.

Survival curve S(t)

Solid = observed failures. Dashed = no further failures were observed before THIS scenario's own clip ended (still censored, not missing data) -- each scenario runs a different clip length, so a shorter one's line legitimately stops earlier than a longer one's, rather than continuing across the whole chart.
